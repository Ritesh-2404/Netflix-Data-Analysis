# 🎬 Netflix Data Analysis & Interactive Dashboard

An end-to-end data analytics project analyzing Netflix content using Python and Power BI to uncover trends, content distribution patterns, and business insights.

---

## 📌 Project Overview

This project explores Netflix’s dataset to analyze content trends, genre distribution, country-wise availability, release patterns, and ratings distribution.

The workflow simulates a real-world data analytics pipeline:
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Insight Extraction
- Interactive Dashboard Development

---

## 🎯 Objectives

- Analyze Netflix content distribution by genre and country
- Identify trends in movie vs TV show releases
- Examine release year growth patterns
- Understand rating classifications and audience targeting
- Build an interactive Power BI dashboard for business insights

---

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Power BI
- CSV Dataset

---

## 📊 Analysis Performed

- Data cleaning and preprocessing
- Handling missing values
- Content type distribution (Movies vs TV Shows)
- Genre frequency analysis
- Country-wise content production
- Year-wise release trend analysis
- Rating distribution insights

---

## 📈 Dashboard Features

- Interactive filters (Year, Type, Country)
- Content type comparison (Movies vs TV Shows)
- Top genres visualization
- Country distribution analysis
- Year-wise growth trends
- Rating breakdown visualization

---

## 💡 Key Insights

- Movies dominate Netflix content compared to TV Shows
- Significant growth in content releases after 2015
- Certain genres like Drama and International content are highly popular
- Content production is concentrated in specific countries
